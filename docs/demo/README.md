## Food enzyme (alpha-amylase)

- [Download Demo Synthetic Dossier ZIP](Demo_Synthetic_Dossier.zip?raw=true) - all 14 PDFs, 49 pages and documentation, using short Windows-safe paths.

The company name is Acme Enzymatic srl. Applicant/contact details are fictional. Visible source scientific values and citations are retained. This use-extension package refers to earlier evidence that is not included; it is not a complete initial application or a new scientific safety assessment.

The ZIP uses ordinary unencrypted ZIP entries with DOS attributes and short ASCII file names. The earlier archive preserved source paths with a trailing-period folder name and a 294-character path; this edition replaces those names. A path-mapping CSV is included. The PDFs remain PDFs, and scientific body text is unchanged.

## Feed additive (6-phytase, *Trichoderma reesei*)

- [Download Demo Synthetic Feed Dossier ZIP](Demo_Synthetic_Feed_Dossier.zip?raw=true) - 56 files (54 PDFs with 556 pages, one .xlsx, one .docx) with documentation, under short Windows-safe paths.
- [Read provenance and limitations](Demo_Synthetic_Feed_Dossier_README.txt).
- [Read the validation report](Demo_Synthetic_Feed_Dossier_validation.json).

Built from the non-confidential version of a feed additive application published on Open EFSA (FEED-2026-38110: a 6-phytase produced by a genetically modified *T. reesei* strain, zootechnical additive for all poultry and all pigs). The applicant is replaced by the fictional Acme Feed Enzymes B.V. and the trade name by AcmePHY® PLUS, in text and scans, with logos removed. All 703 redaction boxes left by EFSA's sanitisation are filled with synthetic content consistent with the data left visible: formulation and TOS, manufacturing process and flow charts, feed and premix compositions, raw stability data, validation appendices, strain characterisation details, names and signatures. Filled values are invented, not the applicant's data. Every page carries a DEMO SYNTHETIC DOSSIER banner, and scanned pages carry an OCR text layer.

The published archive used paths of up to 263 characters (Windows' limit is 260), with a folder name that starts with a space, so it did not unpack on Windows. This edition uses paths of at most 110 characters. A path-mapping CSV and a per-box replacement log are included.

ZIP size: 27,836,392 bytes.
